# Design Decisions

Record decisions that constrain more than one file or discipline. Name records `NNNN-short-title.md`, starting with `0001` when the first real decision is accepted.

Each record should contain:

- status: proposed, accepted, superseded, or rejected;
- date and decision owners;
- context and evidence;
- considered options;
- decision;
- consequences and follow-up; and
- links to affected parts, tests, issues, or commits.

Do not backfill certainty. A proposed architecture remains proposed until the responsible contributors accept it.
