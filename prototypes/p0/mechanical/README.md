# P0 Mechanical

Place owned mechanical source models under [`cad/`](cad/README.md) and selected review/fabrication outputs under [`exports/`](exports/README.md). Assign released parts an identifier and revision using [`docs/part-revisions.md`](../../../docs/part-revisions.md).

Before importing historical files, check ownership and remove backups, autosaves, derived slicer files, and duplicate exports. Preserve original source timestamps in the commit message or an import note when useful.
