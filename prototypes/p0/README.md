# P0 Prototype

P0 is Roverics' reduced-scale, mainly 3D-printed engineering prototype. It exists to test mechanical concepts, electronics, control code, and integration before R1 requirements and design are finalized.

## Working areas

- [`mechanical/`](mechanical/) — editable CAD, reviewed exports, and mechanical notes
- [`electronics/`](electronics/) — schematics, PCB sources, wiring, and bills of materials
- [`firmware/`](firmware/) — embedded/control source and build instructions
- [`tests/`](tests/) — plans, records, configuration data, and results
- [`photos/`](photos/) — curated, captioned evidence with sensitive metadata removed

P0 dimensions and targets remain provisional until supported by committed sources or test records. Do not describe P0 as R1, production hardware, or load-rated hardware.
