# P0 Tests

Keep plans, raw data of reasonable size, analysis, and signed-off results together. Use one directory per activity, named `YYYY-MM-DD_short-description`. Preserve unsuccessful tests and state what changed afterward.

## Test record template

```markdown
# Test title
- Date/time and location:
- Participants:
- Objective:
- Evidence level sought: hand-fit / bench / loaded
- Mechanical part IDs and revisions:
- Electronics revision:
- Firmware commit:
- Power source and limits:
- Instruments and calibration status:

## Setup and procedure
## Acceptance criteria
## Raw evidence
## Results and observations
## Conclusion
## Problems, safety events, and follow-up
```

For the next single-track milestone, record chain/track pitch measurement, sprocket geometry revision, alignment, tension, motor/reduction, voltage and current, speed/command, temperature locations, surface, run duration, derailments/skips, and setup photos or video.
